# UC Berkeley Campus WiFi Heatmap

This website is a live campus WiFi map for UC Berkeley. Anyone can pick a spot on campus, rate the WiFi from 1 to 5, and see how that location compares to the rest of campus.

Ratings are averaged by place and shown on an interactive map, so you can tell which libraries, courtyards, and buildings have a usable connection before you sit down to work.

**Open the site:** [berkeley-campus-wifi-heatmap-dashboard-git-main-justin-aa14.vercel.app](https://berkeley-campus-wifi-heatmap-dashboard-git-main-justin-aa14.vercel.app/)

Built for **PlexTech**.

---

## What you can do

- Rate the WiFi at a campus location
- See the average score for each place
- Browse those scores on a map of campus
